# Alex Audio Converter

A Windows desktop application for downloading and converting audio through a simple graphical interface.

## Features

- Download audio from supported URLs
- Convert local audio files
- Choose between practical quality profiles
- Export to MP3, M4A and FLAC
- Track conversion progress

## Technology

- Python
- CustomTkinter
- FFmpeg and FFprobe
- yt-dlp
- Pillow
- Threading

## Requirements

- Windows 10 or Windows 11
- Python 3.13 when running from source
- FFmpeg and FFprobe available in the system `PATH`

## Installation

Clone the repository:

```powershell
git clone https://github.com/AlexanderHrHristov/alex-audio-converter.git
cd alex-audio-converter


Create and activate a virtual environment:
python -m venv venv
.\venv\Scripts\Activate.ps1


Install the dependencies:

pip install -r requirements.txt


Run the application:

python main.py
