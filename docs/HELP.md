# Alex Audio Converter — Quick Start

## Getting Started

Alex Audio Converter makes it easy to save and convert audio from supported media URLs into formats optimized for different devices and purposes.

### 1. Paste a Media URL

Copy the URL of the media you want to process and paste it into the input field at the top of the application.

Only use content that you own, have permission to download, or are otherwise legally entitled to use.

### 2. Choose an Audio Profile

**Car Standard**
MP3 320 kbps
Best choice for maximum compatibility with car audio systems and older players.

**Car Premium**
M4A / AAC 256 kbps
Efficient high-quality audio for modern cars, phones and media players.

**Fast Original**
Keeps the original audio stream whenever possible without re-encoding.
This is usually the fastest option and avoids additional quality loss.

**Hi-Fi**
FLAC
Lossless output format for high-quality playback and compatible audio equipment.

**Archive**
WAV
Uncompressed audio output suitable for editing, processing and archival workflows.

### 3. Choose the Output Folder

Click **Choose Folder** and select where the converted file should be saved.

### 4. Start Conversion

Click **Convert**.

The progress bar and status message will show the current state of the process.

When conversion is complete, the application will display a confirmation message.

## Important Notes

Converting a compressed source to a higher bitrate or to a lossless format does not restore audio information that was already lost in the original source.

The **Fast Original** profile may produce formats that are not supported by every car stereo or media player.

Availability of media streams and formats depends on the source website and the media itself.

## Troubleshooting

**The conversion does not start**
Check that the URL is valid and that your internet connection is working.

**The downloaded file is not supported by my device**
Try **Car Standard** for maximum compatibility.

**A `.part` file remains in the output folder**
This usually means that the download was interrupted before completion.

**The application reports an error**
Check the URL and try again. Some websites or media may not be supported.
